# CampusNotes

CampusNotes is a simple academic workspace designed to help students organize their subjects and study materials. It provides a clean and responsive interface for accessing subject-wise information.

## Features

- Simple and clean student dashboard
- Subject-wise organization
- Responsive subject cards
- Easy-to-understand interface
- Search functionality to find subjects

## Technologies Used

- **HTML5** – Structure of the web pages
- **CSS3** – Styling and responsive layout
- **Git** – Version control
- **GitHub** – Repository hosting and collaboration

## Getting Started

Follow these steps to run CampusNotes on your computer:

1. Fork or clone the repository.
2. Download or clone the project files.
3. Open the project folder.
4. Open `index.html` in your web browser.
5. Explore the CampusNotes interface.

No additional software installation or build process is required.
