
# CampusNotes

CampusNotes is a simple academic workspace designed to help students organize their subjects and study materials.

## Features

- Simple and clean student dashboard
- Subject-wise organization
- Responsive subject cards
- Easy-to-understand interface

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub

## Project Structure

CampusNotes/
├── index.html
├── style.css
├── README.md
└── .gitignore

## Purpose

This project is developed as part of the Version Control System (CSE25303) Assignment 2 to demonstrate Git and GitHub workflows.

## Latest Update

The project now includes a study motivation section to encourage students to stay organized and focused on their academic goals.
